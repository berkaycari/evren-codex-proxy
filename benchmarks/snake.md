# Snake benchmark

Boş bir proje dizininde aşağıdaki istemi değiştirmeden kullanın:

```text
Create a production-buildable responsive Turkish Snake game using Vite and vanilla JavaScript.

Requirements:
- A 20x20 grid, keyboard controls, mobile direction buttons, score, and localStorage best score.
- Snake grows after food, speeds up gradually, and loses on wall or self collision.
- Reject an immediate 180-degree direction reversal.
- Keep game rules and state transitions in a DOM-free module.
- Add deterministic Node tests for movement, growth, collision, reversal protection, scoring, and reset.
- Use Vite base "./".
- Run tests and production build.
- Do not commit, push, or make unrelated changes.
```

Başlamadan önce dizinin boşluğunu, paket cache/ağ durumunu ve sürümleri kaydedin. Bitince `README.md` içindeki benchmark şablonunu doldurun; tarayıcı, mobil ve erişilebilirlik kabulünü otomatik test sonucu olarak işaretlemeyin.
