# Calculator benchmark

Boş bir proje dizininde aşağıdaki istemi değiştirmeden kullanın:

```text
Create a production-buildable Turkish calculator using Vite and vanilla JavaScript.

Requirements:
- Addition, subtraction, multiplication, division, decimal input, sign toggle, percent, clear, and backspace.
- Keyboard and pointer controls.
- Division by zero must show exactly: Sıfıra bölme tanımsız
- Keep calculation state in a DOM-free module; do not use eval or Function.
- Add deterministic Node tests for the calculation state and error recovery.
- Use Vite base "./".
- Run tests and production build.
- Do not commit, push, or make unrelated changes.
```

Başlamadan önce dizinin boşluğunu, paket cache/ağ durumunu ve sürümleri kaydedin. Bitince `README.md` içindeki benchmark şablonunu doldurun; görsel kabulü otomatik test sonucu olarak işaretlemeyin.
